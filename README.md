# Improve your AI workflows by 1% everyday
Track your skills, tools & config in one place with version control. 
This reduces the cost of updates, it all happens in one place and can be easily shared.
Uses symlinks to link files here to your global config

## What it has
- run ./setup.sh to symlink skills, tools, & hooks
- contains a tool to render claude plans as an editable webpage
- contains several skills i found useful
- contains hooks to rename zellij tabs based on agents progress: yellow working, red needs your input

## Structure
- use skills-global for skills you want to share across work & personal
- use skills-local for skills you do not want to automatically load on setup
